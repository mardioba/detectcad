Imagens para anotar

O sistema usa o padrão YOLO (um .txt por imagem). Para anotar graficamente, use o CVAT (gratuito e local) ou o Label Studio — veja o README, seção “Como anotar”. O botão abaixo mostra os comandos prontos. 
# 1. Instale e suba o CVAT (Docker) — veja https://docs.cvat.ai
# 2. Crie um projeto do tipo "CVAT for images 1.1" com 1-2 classes: chair (e pile)
# 3. Importe as imagens de training/datasets/raw/
# 4. Exporte em "CVAT for images 1.1" → depois converta para YOLO:
#
# O repositório traz um conversor pronto:
#   python -m training.scripts.prepare_dataset --from-cvat export.xml
#
# Alternativa sem Docker: Label Studio
#   pip install label-studio
#   label-studio start
#   e use o conversor: python -m training.scripts.prepare_dataset --from-labelstudio export.json
